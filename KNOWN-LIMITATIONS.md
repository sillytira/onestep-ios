# OneStep 0.4 beta limitations

- Physical installs, phone reminder delivery, retained data after updates/migration, actual phone-to-PC LAN transfer, and offline parent-code behavior on real devices still require acceptance checks. CI/simulator results are not those device results.
- Core planner use is offline. Online enrollment, family linking, task submission/approval, profile/ranking changes, and admin adjustments need the hosted service. Account snapshots are labeled with last sync; a missing snapshot is shown as unknown, not zero. Portable service views poll about every 20 seconds while open; native Bank has manual refresh. No guaranteed instant background delivery.
- Kids identity is email-only and rankings exclude it server-side. A child cannot unlink itself. Parent authorization gates ordinary device sign-out, but signing out does not remove the server family relationship. Only a linked parent can unlink. Parent codes must be set up and synced before offline use; rotations reach offline devices only when they reconnect. Repeated guesses are locally rate-limited. This cannot prevent uninstall, reset, clearing app data, a modified client, or a compromised OS.
- Family invitations establish a trusted-family application link, not verified age/legal guardianship or Apple authorization. Actual TikTok/other-app shielding, app-time redemption, Critical Alerts, and Family Controls entitlements are not enabled. Parent codes cannot replace OS-level parental controls.
- Points are virtual and not purchasable. Parent-assigned family tasks earn their fixed reward once after approval; ordinary private planner tasks are not automatically trusted awards. App-time prices/redemption and fraud-resistant public competition require further work.
- App admin UI provides account/balance inspection, invitation generation, and audited point adjustments. It does not provide DB passwords, service-role keys, unrestricted SQL/schema/billing controls, or every Supabase dashboard feature. Initial owner account creation must be done by the user with the private enrollment key. Email confirmation is deliberately disabled; possession of a bound invitation proves enrollment authorization, not email ownership. Password-reset email delivery is not configured or promised by this beta.
- Project/account keys and sessions are entered at runtime and stored by OS secure storage. A locked/unavailable desktop credential service can prevent online account use; the offline planner still works. Secure-storage/device migration across reinstalls is not guaranteed. Backups/imports contain only planner data and cannot grant roles, mint points, or transfer sign-in sessions.
- Main iOS uses ordinary local notifications and one Live Activity extension. Up to 60 alerts look 14 days ahead; reopen to refill. Notifications obey permissions, Focus/silent settings, and device policy. No critical override, Time Sensitive provisioning, App Group, next-action Home Screen widget, APNs, or unlimited background execution. On iPhone 12, Live Activities use the Lock Screen. Countdown rendering is system-driven; other content updates on app use.
- Android exact-alarm/notification permissions and power policies affect reminders. Desktop timers/banners need the app running and OS notification support. Sleep/exit suspends them. One focus timer supports up to 8 hours; duration timers pause/resume, fixed iOS finish times do not move. Portable UI offers durations.
- Simple daily/weekly task recurrence advances after completion without missed-date backlog. Advanced recurrence, folders/tags, routine Undo/today-only rescheduling, and full portable guided-sequence parity remain future work.
- Wi-Fi uses encrypted foreground private-IPv4 snapshot transfer with explicit replacement/recovery, not continuous merging, discovery, IPv6-only support, or online planner sync. Export both devices before combining separate edits. JSON exports/recovery are readable private data; keep them private.
- New Apple meow.tira.onestep identity cannot share the old tech.sillycat.onestep sandbox automatically. Use the old-ID bridge to export before migrating. Never delete the only planner copy. Free Apple signing expiry, app/App-ID limits, extension signing, and native-IPA reinstall requirements remain. Install only needed companion roles per device.
- Android beta signing is CI-cached and not permanently configured private release signing. Future cached-key expiry may prevent in-place updates; export first. Windows is an unsigned portable bundle requiring its DLL/data files. Linux targets compatible x86-64 GTK3 desktops, not every architecture/distribution.
