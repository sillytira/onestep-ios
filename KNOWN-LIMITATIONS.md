# Beta limitations

- See PLATFORMS.md and INSTALL.md for identity migration. The new iOS app ID does not share the old app's sandbox. Export using the old-ID bridge before changing installations; never delete the only copy of your planner.
- Ordinary notifications only. Apple Family Controls, Time Sensitive provisioning, critical alerts, alarm overrides, and automatic all-day Live Activity renewal are not enabled. Signed physical-device behavior still needs acceptance checks.
- Up to 60 alerts looking 14 days ahead. Reopen regularly to refill. No backlog of missed alerts; future follow-ups may still fire. Quiet hours omit task/routine alerts but do not suppress an explicitly started timer. Routine follow-ups do not cross midnight.
- Android uses native system alarms; power policies and denied permissions can delay them. Desktop banners/timers require the app to remain open and a supported notification system. They do not run after exit or while the PC is asleep.
- One focus timer, up to eight hours. Duration timers can pause/resume; fixed iOS finish times do not move. The portable UI currently offers duration timers. Done/Skip/Snooze/delete stops the item's timer. A paused iOS timer removes the Live Activity countdown until resumed; app snapshots update on foreground actions.
- Simple daily/weekly task recurrence advances only after completion, skipping missed dates without creating a backlog. Completed occurrences stay in history. Undo removes an uncompleted generated successor. Editing/deleting independently progressed successors can create separate tasks; advanced recurrence rules are not implemented.
- Task organization currently has search, list-name text, pinning, and archiving; no folder/tag hierarchy. Routine reorder is currently native iOS only. Guided iOS sequences select the next incomplete step; the portable client currently starts one guided step. Routine Done/Skip Undo and today-only rescheduling are still proposed overhauls.
- No Home Screen next-action widget or App Group. iOS includes one Live Activity extension, using an additional App ID. On iPhone 12 it appears on the Lock Screen. Countdown rendering is system-driven; other content refreshes when the app runs. No APNs or background sync service.
- Transfers are foreground private-IPv4 LAN snapshot copies with expiry, encryption, preview, and recovery. There is no automatic discovery, IPv6-only LAN support, bidirectional conflict merging, or continuous sync. A copied profile does not authenticate ownership of a hosted account.
- Export/recovery JSON is readable. Local storage uses OS/user-account protections; no custom encrypted database or parent PIN lock is provided yet. Uninstalling can remove your data. Keep private backup copies.
- Optional Supabase email-code identity requires a configured hosted project and suitable email delivery. Default provider email is restricted to team addresses/rate-limited; a public launch needs custom delivery. No authentication tokens are retained, no planner content is uploaded, and there is no cloud sync. Hosting has not been provisioned unless the release report says so.
- Android permanent release signing is not configured automatically; the first beta signing key is CI-cached and may expire from that cache. Windows EXE is unsigned and distributed with required DLL/data files. Linux AppImage targets x86-64 compatible GTK 3 systems, not every distribution/architecture.
- Points spending, leaderboard, audited admin balance changes, parent controls, TikTok/app shielding, and a separate points banking application remain product work, not functioning features. Buying a server does not bypass Apple entitlement requirements.
- Native iOS updates need a newly signed/installed IPA. In-app release discovery cannot replace native executables or extend free Apple signing expiry.
- Automated builds and simulator/desktop smoke checks are not physical-phone acceptance evidence. Check persistence, locked offline alerts, follow-up cancellation, day reset, migration, and in-place update retention on your own devices.
