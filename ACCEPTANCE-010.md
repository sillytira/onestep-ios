# OneStep 0.10 — device acceptance

These checks are still open. Synthetic automated tests and renders are recorded separately. Use copies of your planner and keep a verified backup before importing or enabling sync.

1. **Update:** install over the existing Android app with the permanent certificate, or the matching iPhone app with the same signing team/identifier. Verify tasks, routine history and notes remain. Keep the prior app/backup until checked.
2. **Planner:** open More → Planner. Switch Day/Week/Month, select today/another date, edit a task, and check both dated and undated work. Completed work remains visible in its day. Daily routines show their recorded daily state.
3. **Repeats:** create a monthly31st task, complete January's occurrence and check February's clamped day; complete that and check March31. Set an every-two-weeks Monday/Wednesday task. Complete late and early; there should be one next task, with no catch-up alert backlog. Check after a timezone/DST change.
4. **Backups:** export with a saved12+character passphrase. Import a copy on the other platform. Confirm preview/data before replacing. Try a wrong password and a damaged copy: neither may replace data. Confirm the local pre-import recovery file exists. Never test recovery using the only copy.
5. **Language:** select each requested language through settings/More. Verify core navigation/date controls, long labels, large text and restart persistence. Your task titles must remain exactly as entered. Detailed service/admin copy currently falls back to English.
6. **Offline reminders:** with notification permission, create a future reminder and lock the phone offline. Verify initial alert and ten-minute follow-up; complete/skip before the follow-up and verify cancellation. Android exact-alarm permission is optional; power policies still affect timing.
7. **Service setup:** after authenticated deployment of missing006 then007, reconnect. Verify existing balances/accounts/family links remain. Confirm1point=1minute, daily earning/spending ceilings, separate XP and opt-in rankings, and no child public profile. Native blocking additionally needs genuine Apple capabilities, selection and authorization.
8. **Cloud sync:** use one test account on two devices and the same saved sync passphrase. Opt in on both after checking local data. Verify independent additions merge; after both have synced, edit the same task while one is offline, then reconnect and choose a conflict explicitly. Delete/edit the same record as another case. Edit locally during upload; that edit must survive. Check timers remain device-local and account-switch does not silently publish another account's local planner.
9. **Moderation:** use separate owner/adult test accounts. Owner grants one capability at a time; moderator sees only assigned tools. Attempt unassigned actions, owner suspension and permission delegation: all must fail. Verify email/child list redaction, audited idempotent point adjustments, revoke permissions and verify denial. Suspension blocks OneStep APIs while preserving offline data and does not pretend to disable Supabase Auth sign-in.
10. **Beta fairness:** verify XP and earned-point/task rankings use the account's earning cohort. A future production cohort must not inherit beta-earned ranking totals. Children and opted-out profiles stay absent.

For Screen Time, widgets, signed Live Activities, offline guardian codes and family approval checks, also use the existing ACCEPTANCE.md and SCREEN-TIME-SIGNING.md. No test here grants a missing Apple entitlement or verifies legal guardianship.
